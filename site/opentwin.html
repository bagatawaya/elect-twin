THE 0.5.0 STUDIO

Five workspaces. One set of boundaries.

01

My Command

Move, resize, rename, add, delete, and undo persistent Bento widgets. Task Center saves policy separately from triggers; a saved toggle never starts an autonomous job.

02

Open News

Transparent local framing heuristics separate FACT, INFERENCE, and COULDNT_VERIFY. URLs are not fetched. Audio Brief stays unavailable until a speech engine is connected.

03

My AI & Code

OpenSkills v2 indexes 1,501 entries: 300 source-prompt playbooks and 1,201 metadata-only records. Local FTS5 search builds inspectable builder, challenger, and verification bundles.

04

Smart Model-Version Router

Select automatic, economy-locked, or frontier-focused routing only among declared, connected model IDs. Reasons and alternatives stay visible; routing never dispatches a request.

05

Smart Swarm Gate

Deterministic fan-out advice detects shared-state collisions, sequential or external-write intent, and budget violations. Results retain execution_started: false; external writes need separate approval.

06

Rooms, OpenZoo & SVG Studio v2

Use Solo 2-AI and deterministic multiplayer Rooms, inspect clearly labeled OpenZoo fixtures, and render seven kinds of procedural SVG artwork with SHA-256 remix receipts at zero API cost.
